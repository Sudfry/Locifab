# Locifab 发布流程

> 适用范围：Windows x64 正式版发布  
> 当前版本：11.0.3  
> 发布形式：单文件 EXE、MSIX（Microsoft Store）、GitHub 源码与 Release

---

## 1. 发布总览

```text
改版本号
  ↓
构建单文件 EXE
  ↓
运行完整测试
  ↓
生成 MSIX
  ↓
签名与检测
  ↓
GitHub 提交 / Release
  ↓
Microsoft Store 提交
  ↓
归档发布物
```

发布必须满足：

- 核心自测通过。
- 14 套流水线模板通过。
- 应用可启动。
- MSIX 可打包、可签名、可解包。
- 版本号、标题、清单、README 一致。

## 2. 发布前准备

### 2.1 环境

- Windows 10 / 11 x64
- .NET 8 SDK
- Windows SDK（MakeAppx、SignTool）
- Git
- PowerShell 5.1 或 7
- Python + Pillow（仅重新生成图标时需要）

检查工具：

```powershell
dotnet --version
git --version

Get-ChildItem "C:\Program Files (x86)\Windows Kits\10\bin" -Recurse -Filter makeappx.exe |
  Where-Object FullName -match 'x64' | Select-Object -First 1

Get-ChildItem "C:\Program Files (x86)\Windows Kits\10\bin" -Recurse -Filter signtool.exe |
  Where-Object FullName -match 'x64' | Select-Object -First 1
```

### 2.2 工作目录

```powershell
cd C:\Users\zxyzx\Desktop\LoacalCraft
```

### 2.3 确认工作区干净

```powershell
git status
```

发布前应没有未提交的源码改动。

## 3. 修改版本号

一次发布需要同步修改以下位置。

### 3.1 项目版本

文件：`src/LocalCraft.App/LocalCraft.App.csproj`

```xml
<Version>11.0.3</Version>
<AssemblyVersion>11.0.3.0</AssemblyVersion>
<FileVersion>11.0.3.0</FileVersion>
```

### 3.2 窗口标题

文件：`src/LocalCraft.App/MainWindow.xaml`

```xml
Title="Locifab 11.0.3 · 本地文件工坊"
```

同时检查页脚版本文字。

### 3.3 MSIX 清单

文件：`msix/layout/AppxManifest.xml`

```xml
<Identity
    Name="Sudfry.Locifab"
    Publisher="CN=Sudfry"
    Version="11.0.3.0"
    ProcessorArchitecture="x64" />
```

说明：

- `Name` 与 `Publisher` 是占位值。
- 正式提交 Store 时必须替换为 Partner Center 的值。
- `Version` 必须高于上一次 Store 提交。

### 3.4 README 与文档

- `README.md` 的版本徽章。
- `docs/答辩文档.md` 的版本。
- 如有必要更新 `docs/测试报告.md`。

## 4. 构建单文件 EXE

```powershell
dotnet build .\LocalCraft.sln -c Release
```

发布：

```powershell
dotnet publish .\src\LocalCraft.App\LocalCraft.App.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true `
  -p:PublishTrimmed=false `
  -p:PublishReadyToRun=false `
  -p:DebugType=None -p:DebugSymbols=false `
  -o .\publish\win-x64
```

输出：

```text
publish\win-x64\Locifab.exe
```

启动检查：

```powershell
$env:LOCIFAB_DATA_DIR="$PWD\.ui-release"
.\publish\win-x64\Locifab.exe
```

确认：

- 窗口标题正确。
- 侧栏、首页、设置、流水线可打开。
- 设置底部作者按钮可点击。
- 数据目录可写。

## 6. 生成 MSIX

### 6.1 发布包目录

MSIX 不使用单文件 EXE，而是使用完整自包含目录，避免运行时解包目录问题：

```powershell
dotnet publish .\src\LocalCraft.App\LocalCraft.App.csproj `
  -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=false `
  -p:PublishTrimmed=false `
  -p:PublishReadyToRun=false `
  -p:DebugType=None -p:DebugSymbols=false `
  -o .\publish\msix-x64
```

确认：

```powershell
Test-Path .\publish\msix-x64\Locifab.exe
```

### 6.2 图标

图标位于：

```text
msix/template/Assets
```

包含：

- StoreLogo.png（50×50）
- Square44x44Logo.png
- Square44x44Logo.scale-200.png
- Square150x150Logo.png
- Square150x150Logo.scale-200.png
- Square310x310Logo.png
- Wide310x150Logo.png
- SplashScreen.png

重新生成：

```powershell
python .\msix\gen-assets.py
```

### 6.3 打包

```powershell
powershell -ExecutionPolicy Bypass -File .\msix\build-msix.ps1
```

指定 Store 身份和证书：

```powershell
powershell -ExecutionPolicy Bypass -File .\msix\build-msix.ps1 `
  -PackageName "PartnerCenter.Identity.Name" `
  -Publisher "CN=PartnerCenter.Publisher" `
  -Version "11.0.3.0" `
  -CertPath "C:\path\store-signing.pfx" `
  -CertPassword "证书密码" `
  -Output "Locifab-Store-11.0.3.msix"
```

## 7. MSIX 检测

### 7.1 签名验证

```powershell
signtool verify /pa /v .\msix\Locifab-11.0.3.msix
```

期望：

```text
Number of errors: 0
```

### 7.2 解包验证

```powershell
makeappx unpack /o /p .\msix\Locifab-11.0.3.msix /d .\msix\unpacked
```

期望：

```text
Package extraction succeeded.
```

### 7.3 清单检查

```powershell
Get-Content .\msix\layout\AppxManifest.xml
```

检查：

- Identity Name / Publisher / Version
- Executable = Locifab.exe
- EntryPoint = Windows.FullTrustApplication
- Capabilities 包含 runFullTrust
- 图标路径存在

### 7.4 启动检查

```powershell
$env:LOCIFAB_DATA_DIR="$PWD\.ui-msix"
.\msix\layout\Locifab.exe
```

确认窗口标题和功能正常。

### 7.5 安装检查

本机测试需要：

1. 以管理员 PowerShell 信任测试证书：

```powershell
certutil -addstore TrustedPeople .\msix\Locifab-Test.cer
certutil -addstore Root .\msix\Locifab-Test.cer
```

2. 安装：

```powershell
Add-AppxPackage .\msix\Locifab-11.0.3.msix
```

3. 启动：

```powershell
Get-AppxPackage -Name Sudfry.Locifab
```

常见错误：

| 错误 | 原因 |
|---|---|
| 0x800B0109 | 证书未加入本机信任 |
| 0x80073CFF | 未开启开发者模式/旁加载 |
| 0x80073CF0 | 包结构、签名或文件缺失 |

建议统一目录：

```text
Locifab-11.0.3/
├─ Locifab.exe
├─ 启动Locifab.cmd
├─ README.md
├─ 答辩文档.md
├─ 测试报告.md

├─ SHA256.txt
├─ 版本说明.txt
├─ 源码.zip
├─ 源码.bundle
└─ MSIX/
   ├─ Locifab-11.0.3.msix
   ├─ Locifab-Test.cer
   ├─ AppxManifest.xml
   ├─ STORE-发布指南.md
   ├─ 检测报告.md
   ├─ PRIVACY.md
   ├─ SHA256.txt
   └─ store-assets/
```

生成 EXE 校验：

```powershell
Get-FileHash .\Locifab-11.0.3\Locifab.exe -Algorithm SHA256 |
  ForEach-Object { "$($_.Hash)  Locifab.exe" } |
  Set-Content .\Locifab-11.0.3\SHA256.txt -Encoding ASCII
```

生成 MSIX 校验：

```powershell
Get-FileHash .\Locifab-11.0.3\MSIX\Locifab-11.0.3.msix -Algorithm SHA256 |
  ForEach-Object { "$($_.Hash)  Locifab-11.0.3.msix" } |
  Set-Content .\Locifab-11.0.3\MSIX\SHA256.txt -Encoding ASCII
```

## 9. GitHub 发布

### 9.1 提交源码

```powershell
git status
git add -A
git commit -m "Release Locifab 11.0.3"
git push origin main
```

如果当前网络无法访问 GitHub：

- 使用 GitHub Desktop：`Add local repository` → `Publish repository`。
- 使用 PAT 脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\push-with-token.ps1
```

- 或使用 `dist-upload/Locifab-11.0.3-source.zip` 网页上传。
- 或使用 `dist-upload/Locifab-11.0.3.bundle` 在另一台电脑推送。

### 9.2 创建 Release

1. 打开 <https://github.com/Sudfry/Locifab/releases>。
2. `Draft a new release`。
3. Tag：`v11.0.3`。
4. 标题：`Locifab 11.0.3`。
5. 上传：
   - `Locifab.exe`
   - `测试数据与模板.zip`
   - `Locifab-11.0.3.msix`
   - `SHA256.txt`
6. 发布。

### 9.3 仓库信息

- Description：`Fully offline Windows file workbench with reversible batch operations and pipelines`
- Topics：`csharp`, `dotnet`, `wpf`, `offline`, `file-manager`, `batch-rename`, `pipeline`
- License：MIT

## 10. Microsoft Store 发布

### 10.1 Partner Center

1. 登录 <https://partner.microsoft.com/dashboard>。
2. 创建应用，预留名称 `Locifab`。
3. 记录：
   - `Package/Identity/Name`
   - `Package/Identity/Publisher`
4. 替换清单中的占位值。
5. 使用匹配 Publisher 的代码签名证书重新签名。

### 10.2 上传包

1. 进入 **Packages**。
2. 上传 `Locifab-Store-11.0.3.msix`。
3. 查看认证报告。
4. 修复后重新上传。

如果页面要求 `.msixupload`：

- 使用 Visual Studio 的 **Create App Packages → Microsoft Store** 生成。
- 或确认当前 Partner Center 是否接受 `.msix` / `.msixbundle`。

### 10.3 商店资料

- 应用名称：Locifab 本地文件工坊
- 分类：Utilities & tools
- 简短描述：完全离线的文件处理工作台。
- 详细描述：重命名、转换、压缩、去重、校验、备份、流水线。
- 隐私政策：使用 `msix/PRIVACY.md` 内容发布到可访问网页。
- 支持链接：<https://github.com/Sudfry/Locifab>
- 截图：使用 `MSIX/store-assets`。
- 年龄分级：按问卷填写。
- 定价：免费或按需。

### 10.4 认证注意

- 包版本必须递增。
- `Publisher` 必须与证书 Subject 一致。
- 不能包含测试证书、测试数据、私钥。
- 首次启动不能依赖联网。
- 不能写入安装目录；Locifab 已使用本地数据目录并提供回退。
- 完整信任应用需要说明用途。

## 12. 回滚

### 12.1 回滚 GitHub

```powershell
git revert <commit>
git push origin main
```

### 12.2 回滚 Store

- Store 不支持删除已发布版本。
- 上传更高版本修复。
- 必要时在 Partner Center 取消发布。

### 12.3 回滚本地发布物

保留上一个版本目录，例如：

```text
Locifab-11.0.2/
Locifab-11.0.3/
```

不要覆盖旧版本，便于对比与回退。
