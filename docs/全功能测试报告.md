## 1. 发现并修复的问题

### 问题：流水线模板没有导入入口

**原因**

- 11.0.5 及更早版本，所有模板都塞在 `pipeline-presets.json` 里，没有直观入口。
- 11.1.0 已改为 `流水线模板` 文件夹，一个模板一个 `.json`；旧文件首次启动自动拆分迁移。
- 本轮同时验证了界面「导入模板文件」和文件夹加载两条路径。

**修复**

- 在流水线右侧“模板 / 预设”增加「导入模板文件」按钮。
- 同时把演示模板直接内置到应用中：
  - 交付整理-全流程
  - 文档隐私交付（演示）
  - 客户资料归档（演示）
- 内置 6 个演示功能配置：重命名、图片压缩、图片检查、清单、分类、ZIP。
- 支持：
  - JSON 数组
  - 单个模板对象
- 导入后：
  - 追加到模板列表
  - 自动保存到本机
  - 同名模板自动追加“（导入）”
  - 立即选中导入后的模板
- 文件：`PipelineViewModel.ImportPresetFile`、`PipelineView.xaml`

## 6. 使用方式

### 导入流水线模板

1. Locifab → 任务流水线。
2. 右侧“模板 / 预设”。
3. 点「导入模板文件」。
4. 选择：
   `视频演示数据-11.0.3\05-模板与说明\流水线模板.json`
5. 模板列表出现：
   - 交付整理-全流程
   - 文档隐私交付
   - 客户资料归档
6. 选择「交付整理-全流程」，设置源目录/输出目录，先预览再执行。

### 一键安装脚本

`视频演示数据-11.0.3\05-模板与说明\导入模板.ps1`
