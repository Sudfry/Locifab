## 6. 商店文案

### 简短描述

```text
完全离线的 Windows 文件处理工作台：批量重命名、格式转换、图片压缩、去重、校验、备份与可回退流水线。
```

### 详细描述

```text
Locifab 把常用文件操作集中到一个离线应用：批量重命名、格式转换、图片压缩、图片检查、内容去重、相似照片、备份同步、压缩解压、校验清单、分类移动、时间属性、拆分合并和任务流水线。

所有批量操作都遵循“先预览、再执行、可回退”。文件不上传、不联网、不调用外部 API。

不包含广告，不收集个人数据。
```

### 产品功能

```text
批量重命名
格式转换
图片压缩
图片检查
内容去重
相似照片
备份同步
压缩与解压
SHA-256 校验
扫描与分类
时间与属性
拆分与合并
目录模板
任务流水线
回退中心
完全离线
```

1. 安装后启动 Locifab.exe。
2. 首页显示批量重命名、图片压缩、内容去重、任务流水线等功能。
