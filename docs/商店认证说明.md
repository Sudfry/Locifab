# Microsoft Store 认证说明与系统要求

## 1. 认证说明（可直接粘贴）

### 中文版

```text
Locifab 是一款完全离线的 Windows 桌面文件处理工具，使用 .NET 8 + WPF 开发，采用自包含发布，不需要用户安装 .NET 运行时。

测试说明：
1. 应用无需登录、无需联网、无需测试账户。
2. 安装后直接启动 Locifab.exe。
3. 首页会显示批量重命名、格式转换、图片压缩、内容去重、任务流水线等功能。
4. 任选一个本地文件夹即可测试：
   - 批量重命名：选择文件夹 → 预览 → 执行 → 回退中心恢复。
   - 图片压缩：选择文件夹 → 设置目标 KB → 预览 → 执行。
   - 任务流水线：选择源目录和输出目录 → 预览 → 执行。
5. 所有操作均为本地文件操作，不上传文件、不访问网络。
6. 设置页底部“打开 GitHub”只会在用户主动点击时调用系统浏览器。

其他说明：
- 不包含非 Microsoft 驱动程序。
- 不安装 NT 服务。
- 不包含后台音频。
- 不包含隐藏功能、内购或需要解锁的功能。
- 不需要管理员权限；数据默认写入 %LOCALAPPDATA%\Locifab，不可写时回退到程序目录或临时目录。
- 应用为完整信任 Win32 桌面应用，使用 runFullTrust 能力，原因是需要访问用户选择的本地文件夹并执行文件操作。
```

### English version

```text
Locifab is a fully offline Windows desktop file utility built with .NET 8 and WPF. It is self-contained and does not require a separate .NET runtime installation.

How to test:
1. No account, sign-in, network connection, or test credentials are required.
2. Launch Locifab.exe after installation.
3. The home page lists batch rename, format conversion, image compression, duplicate detection, and pipelines.
4. Pick any local folder to test:
   - Batch rename: select folder -> preview -> execute -> restore from Undo Center.
   - Image compression: select folder -> set target KB -> preview -> execute.
   - Pipeline: select source and output folders -> preview -> execute.
5. All operations are local file operations. No files are uploaded and no network access is used.
6. The "Open GitHub" button in Settings only opens the system browser when the user clicks it.

Additional notes:
- No non-Microsoft drivers.
- No NT services are installed.
- No background audio.
- No hidden, conditional, locked, or purchasable features.
- No administrator rights are required. Data is stored in %LOCALAPPDATA%\Locifab by default, with fallback to the application folder or temp directory.
- This is a full-trust Win32 desktop app using the runFullTrust capability because it must access user-selected local folders and perform file operations.
```

## 2. 系统要求建议

| 功能 | 最低硬件 | 推荐硬件 | 说明 |
|---|---|---|---|
| 触摸屏 | 不勾选 | 不勾选 | 不要求触摸屏 |
| 键盘 | 勾选 | 勾选 | 文本输入、路径输入需要键盘 |
| 鼠标 | 勾选 | 勾选 | 桌面文件操作以鼠标为主 |
| DirectX | 勾选 | 勾选 | WPF 渲染需要 DirectX 9 级别图形 |
| 内存 | 4 GB | 8 GB | .NET 8 WPF 桌面应用 |
| 存储 | 300 MB | 500 MB | MSIX 安装后约 161 MB，预留更新空间 |
| 图形 | 集成显卡 | 独立显卡/集成显卡 | 不要求独立显卡 |
| 摄像头 | 不勾选 | 不勾选 | 不使用 |
| NFC | 不勾选 | 不勾选 | 不使用 |
| 蓝牙 | 不勾选 | 不勾选 | 不使用 |

### 操作系统

- 最低：Windows 10 1809（10.0.17763）
- 推荐：Windows 10 22H2 / Windows 11
- 架构：x64

## 4. 注意

- 不要把“测试数据与模板.zip”作为审核依赖；审核人员可用任意本地文件夹测试。
- 不要要求测试账户。
- 不要写“需要联网激活”。
- 不要把 GitHub 访问写成应用功能；它只是用户主动打开的外部链接。
- 如果审核询问 runFullTrust，说明这是本地文件工具，必须访问用户选择的文件夹。
