# Locifab 11.1.0

完全离线的 Windows 文件处理工作台，正式版发布。

## 本次更新

- 流水线模板改为「一个模板一个 JSON」，位置：
  `%LOCALAPPDATA%\Locifab\流水线模板\`
- 旧版 `pipeline-presets.json` 首次启动自动拆分迁移，原文件保留为 `.bak`
- 新增「打开模板文件夹」「刷新模板列表」「导入模板文件」
- 内置演示流水线：
  - 交付整理-全流程
  - 文档隐私交付（演示）
  - 客户资料归档（演示）
- 内置演示功能配置：
  - 重命名、图片压缩、图片检查、清单、分类、ZIP
- 修复模板导入后不显示的问题
- 视频演示数据更新到 11.1.0
- Microsoft Store MSIX 更新到 11.1.0

## 说明

- 完全离线，不上传文件、不联网、不调用外部 API。
- 批量操作遵循「先预览、再执行、可回退」。
- 单文件启动如遇到临时目录权限问题，请使用 `启动Locifab.cmd`。
