# Microsoft Store 中文（简体）列表文案

## 描述

```text
Locifab 本地文件工坊是一款完全离线的 Windows 文件处理工具，把日常高频操作集中到一个应用里：批量重命名、格式转换、图片压缩、图片检查、内容去重、相似照片、备份同步、压缩解压、校验清单、分类移动、时间属性、拆分合并、目录模板和任务流水线。

所有批量操作都遵循“先预览、再执行、可回退”：执行前生成计划，执行时写入本机日志，完成后可在回退中心按批次恢复。文件不上传、不联网、不调用外部 API，适合整理照片、文档、素材、交付包和课程资料。

主要特点：
• 完全离线：文件与日志只保存在本机。
• 可回退：重命名、移动、转换、提取等操作有记录。
• 可组合：把多个步骤保存为流水线，一键重复执行。
• 可复用：为单个工具保存多套配置，导入流水线。
• 轻量：自包含运行，不需要安装 .NET。
• 中文界面：清晰的分类、预览和状态提示。

Locifab 不包含广告、不收集个人数据，也不会后台上传文件。
```

## 产品名称
