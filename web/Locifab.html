界面没能启动

本地服务的地址能打开，但页面脚本没有跑起来。常见原因和解决办法：

  1. 系统代理拦住了 127.0.0.1（装了 Clash / v2ray / 各类加速器时最常见）。
    请在代理软件里把 127.0.0.1 和 localhost 加入直连（绕过）列表， 或临时关掉系统代理后点下面的按钮重新加载。
  2. 主程序已经退出。重新双击 Locifab.Web.exe，再刷新本页。
  3. 浏览器内核太旧。本界面需要 Chromium 内核（Edge / Chrome）， 不支持 IE 模式和部分国产浏览器的兼容模式。

关于扩展名：模板里只要出现 {ext} 或 {extname}， 程序就认为你已经自己安排好了扩展名；没写的话会自动补上原扩展名。
序号写法：{n:03d} 补零到 3 位（001）， {n:5d} 补零到 5 位，{n} 不补零。索引 {i} 同理。
日期写法：{date}=20261016、 {time}=143025， 也可以自定义 {mtime:%Y-%m-%d}。
关于 EXIF / ID3：{date} 用的是文件修改时间， {exif:date} 用的是照片的拍摄时间，两者常常不是同一天。 EXIF 只对 JPEG / TIFF / 各类相机原始格式有效，ID3 只对音频文件有效； 读取期间不会联网、不会修改文件。
读不到元数据时：那个位置会写成 未知， 比如 未知_未知_005.jpg。这样预览表里一眼就能看出 哪些文件没有元数据，你可以去掉那几行，而不是让文件名里出现一个看不出原因的空洞。
