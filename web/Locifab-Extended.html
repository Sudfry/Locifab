Locifab 扩展工具

图片 · 拆分合并 · 校验清单 · 编码 · 差异 · 模板 · 相似照片
输出：未选择文件夹（将逐个下载）

图片缩放 / 转换

浏览器内重新编码，默认移除 EXIF；输出到本地文件夹。

图片拼接长图

纵向或横向拼接，原图不修改。

隐私元数据清理

图片重新编码，不保留 EXIF；适合 JPG/PNG/WebP。

相似照片

64 位 dHash 画面比较，只读分析，不删除文件。

文件拆分 / 合并

拆分生成分片；合并按文件名顺序。原文件不删除。

校验与文件夹清单

SHA-256 完整性校验；可导出 CSV。

编码 / 换行

UTF-8 与 BOM、CRLF/LF 转换；生成副本。GBK 输入会自动识别。

文本差异

逐行对比，只读，不上传。

ZIP 压缩 / 解压

浏览器内生成/读取 ZIP；解压需要先选择输出文件夹。路径会做安全过滤。

空目录 / 零字节清理

需要 Edge/Chrome 并授权目录。先扫描预览，再确认删除；不会碰非空目录和非零文件。

时间与属性（本地桥接）

通过本地桥接修改 Windows 时间戳/文件属性；先预览，执行后可回退。需要后端窗口运行。

任务流水线

把 ZIP 和 SHA-256 审计串成一条本地任务；输出到本地文件夹。

导出与排版

把文本导出为 Markdown / HTML / Word（HTML 兼容格式）；PDF 使用浏览器打印。

全局搜索

在当前浏览器可读的文件夹内按名称/相对路径过滤，只读，不上传。

目录模板

每行一个路径，/ 结尾创建文件夹，其余创建空文件。需要先选择输出文件夹。
