# Locifab 网页版

这是 Locifab 的“HTML 界面 + 本地服务”版本，不是纯浏览器单文件版。

发布目录结构：

```text
publish\win-x64\
├─ Locifab.Web.exe              桌面版
├─ 启动网页版.cmd              网页版入口
└─ web\
   ├─ Locifab.html          主界面
   ├─ Locifab-Extended.html 扩展工具
   ├─ Locifab.Web.exe           本地后端
   ├─ WebView2Loader.dll
   ├─ 启动网页版.cmd
   ├─ Start-Web.ps1
   ├─ FileBridge.ps1
   ├─ Stop-Web.ps1
   ├─ 停止网页版.cmd
   └─ 打开扩展工具.cmd
```

网页版入口在桌面版旁边，所有网页文件都收在 `web\` 目录里。

## 启动

双击 `启动网页版.cmd`（内部调用 `Start-Web.ps1`）：

1. 启动本地后端（仅监听 `127.0.0.1:9500`）和时间属性桥接（9501）。
2. 自动打开 `Locifab.html`。
3. 保持后端窗口打开，关闭后主界面功能失效。

扩展工具页通过 `http://127.0.0.1:9501/` 提供：双击 `打开扩展工具.cmd`，或从主界面左侧“扩展工具”进入。用 localhost 打开是为了让 Edge/Chrome 允许直接写入本地文件夹。

## 本地文件夹

- 主界面通过本地后端直接读写本机路径。
- 扩展工具页右上角可“选择输出文件夹”，Edge/Chrome 会把图片、拆分分片、CSV 等直接写入该文件夹。
- 浏览器不支持目录写入时，自动改为逐个下载；不选输出文件夹时也使用下载。
- `目录模板` 需要 Edge/Chrome 并先选择输出文件夹。
- 扩展工具右上角“撤销本次输出”可删除本次写入输出文件夹的文件；下载模式需要手动删除。

## 覆盖范围

主界面复用 14 个模块：重命名、整理、转换、文本替换、去重、摘要、备份、监控、表格、历史、环境、链接、在线说明、设置。

扩展工具新增 12 个模块（校验卡片同时支持清单验证/HTML 报告）：图片缩放/转换、图片拼接、隐私元数据、相似照片、文件拆分/合并、SHA-256 校验/清单、编码/换行、文本差异、目录模板、全局搜索、ZIP 压缩/解压、空目录/零字节清理、任务流水线、导出与排版。

## 与桌面版 30 页的对齐情况

| 桌面页 | 网页版状态 |
|---|---|
| 重命名、文本替换、去重、摘要、表格、备份、监控、历史、设置 | 已覆盖（主界面） |
| 扫描分类、格式转换 | 已覆盖（主界面“整理 / 转换”） |
| 图片处理、相似照片、隐私元数据、拆分合并、编码换行、目录模板、文本差异、图片拼接、全局搜索 | 已覆盖（扩展工具） |
| 校验与清单、文件夹清单 | 已覆盖（SHA-256 表、CSV、`.sha256` 清单验证、HTML 审计报告） |
| ZIP 压缩/解压、空目录/零字节清理 | 已覆盖（浏览器端） |
| 时间戳/文件属性 | 已覆盖（FileBridge.ps1 本地桥接） |
| 任务流水线、导出与排版 | 已提供浏览器版（ZIP+审计流水线；Markdown/HTML/Word .doc/打印 PDF） |

当前达到 **30/30 页的功能覆盖**，但不是桌面版 100% 行为一致：导出 Word/PDF、流水线和文件时间属性仍有实现差异。

## 安全

- 后端只监听 `127.0.0.1`，不要暴露到局域网或公网。
- 当前后端使用固定 token `LOCIFAB`；本机其他程序知道 token 时可以调用接口。
- `Stop-Web.ps1` 通过 9500/9501 的监听进程 PID 停止服务，避免误杀其他 PowerShell。
- 所有扩展工具都在浏览器本地处理，不上传文件。
- 时间戳/属性桥接只监听 `127.0.0.1:9501`，同样使用固定 token。
