# 目录模板 · 测试流程

## 目标
验证从文本模板批量创建目录和空文件，以及只删除本次创建项。

## 测试数据
- 无预置文件；可在本文件夹内创建 `项目A`。

## 步骤
1. 进入「目录模板」，目标文件夹选本目录。
2. 模板输入：
   ```
   项目A/
   项目A/文档/
   项目A/素材/
   项目A/说明.md
   ```
3. 预览结构，确认 4 项，执行。
4. 检查目录和空文件已创建；在 `说明.md` 写入内容后回退。
5. 确认回退只删除仍为空的目录/文件，已写入的文件保留。

## 预期
- 不覆盖已有目录或文件。
- 回退不会删除用户后来写入的内容。
