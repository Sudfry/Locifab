# 导出与排版 · 测试流程

## 目标
验证 Markdown / DOCX / PDF 三种导出、中文排版、预览和回退。

## 测试数据
- `导出示例.md`

## 步骤
1. 进入「导出与排版」，添加 `导出示例.md`。
2. 勾选 Markdown、Word DOCX、PDF，设置输出文件夹。
3. 点击刷新预览，确认 3 个输出目标。
4. 执行导出，打开三个文件检查标题、列表、粗体和中文标点。
5. 进入「回退中心」删除本次导出，确认原文档保留。

## 预期
- 三个文件均生成，PDF 中文标题和段落排版正常。
- 输出不覆盖原文档。
- 回退只删除本次生成的文件。

## 注意
PDF 是本地排版后渲染为页面图像，文字不可选中；这是已知边界。
