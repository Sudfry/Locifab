# 文件夹清单 · 测试流程

## 目标
验证 CSV/HTML 清单、体积统计、修改时间和可选 SHA-256。

## 测试数据
- `报告.txt`
- `数据.csv`
- `子目录/说明.md`

## 步骤
1. 进入「文件夹清单」，选择本文件夹。
2. 勾选包含子文件夹与「计算 SHA-256」。
3. 点击只读扫描，确认 3 个文件。
4. 格式选 CSV，输出 `清单.csv`，生成清单并打开。
5. 格式切 HTML，输出 `清单.html`，生成并在浏览器打开。
6. 进入回退中心，删除本次生成的清单。

## 预期
- CSV/HTML 含相对路径、大小、时间和 SHA-256。
- 中文路径正常。
- 输出不覆盖已有文件；回退删除清单。
