# Locifab 测试数据与测试流程

本目录用于 Locifab v3.0 的功能验收。**每个分类目录都有自己的 `测试流程.md`**，包含测试目标、测试数据、操作步骤、预期结果和复位方法。

## 使用方式

1. 先把整个 `测试数据` 文件夹复制到桌面或临时目录，避免在项目目录里直接做批量操作。
2. 按编号顺序测试；也可以只选需要的分类。
3. 所有会产生文件变更的操作，测试完成后通过「回退中心」恢复，或重新复制本目录。
4. 外部 Office/PDF 转换能力取决于本机 LibreOffice；在线功能按约定固定关闭。

## 整体验收建议

1. 先测 01、03、04、05、07，确认核心文件操作与回退。
2. 再测 02、06、10，确认文档、图片和表格产物。
3. 测 08、09，确认备份与监控不会自动改文件。
4. 最后测 11–15，确认环境、链接、离线约束和外观设置。
5. 全流程结束后检查 `回退中心`：正常完成的批次应可回退，失败批次应有明确错误。

## 备注

- `07-扫描与分类` 中的媒体/压缩包是用于分类的占位文件，不用于播放或解压。
- `10-表格处理` 包含 CSV 与 XLSX；旧版 `.xls` 不在支持范围。
- 测试产生的日志与备份在 Locifab 数据目录中；可在「设置 → 打开数据目录」查看。
