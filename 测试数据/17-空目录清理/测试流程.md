# 空目录清理 · 测试流程

## 目标
验证空文件夹和 0 字节文件的扫描、清理与恢复。

## 测试数据
- `空目录/更深的空目录`（空目录）
- `零字节占位.txt`（0 字节）
- `保留文件.txt`（正常文件）

## 步骤
1. 进入「空目录清理」，选择本文件夹。
2. 点击只读扫描，确认预览包含 2 个空目录和 1 个零字节文件。
3. 执行清理，确认空目录与零字节文件消失，`保留文件.txt` 仍在。
4. 进入回退中心，回退本次清理。
5. 确认目录层级和零字节文件恢复。

## 预期
- 清理不递归删除非空目录。
- 非 0 字节文件不在清理列表。
- 回退后恢复原路径和空内容。

## 注意
空目录/零字节文件本身不含数据；回退会重建它们，但不保证原始时间戳。
